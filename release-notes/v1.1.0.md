First public release of Fit To Screen.

**What it does**
- Raises Balatro's top and bottom padding from 0.7 to 1.3 tiles, so the whole game scales down about 9% and tall pause menus and sidebars from stacked mods are no longer clipped at the screen edges.
- Keeps the All-In-Jest Load Bearing Coconut area's "1/1" counter off screen. This is done from this mod, so All-In-Jest updates do not undo it.

**Install**
Unzip `FitToScreen-v1.1.0.zip` into `%AppData%\Balatro\Mods` so you end up with `Mods\FitToScreen`, then restart Balatro. Needs Lovely. Steamodded is needed for the coconut part.

**Tune it**
Edit the `1.3` in `Mods\FitToScreen\lovely.toml`. Higher means more margin and a smaller game. `0.7` is the base game value.

Confirmed working on Windows 11, 3840 x 2160 Borderless, Steam. Not tested elsewhere.
